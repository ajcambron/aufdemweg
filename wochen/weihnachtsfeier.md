# Weihnachtsfeier
December 20, 2026 · DSB Hall
{: .fs-5 .text-grey-dk-000 }

## Auf einen Blick

A celebration, not a packet day. The class performs the skits written in [Week 11]({{ '/wochen/woche-11/' | relative_url }}), sings, and writes Christmas cards. There's no new material and nothing to grade.

{: .important }
Check with each skit group at the start: who's here, who's missing, and whether lines need to be reassigned. A group missing a member can cut that role's lines or hand them to the seller.

## Ablauf

| Time | What | Notes |
| :--- | :--- | :--- |
| 0:00–0:15 | Ankommen | Greet with *Frohe Weihnachten!* Groups find each other and run their skits once quietly. |
| 0:15–0:45 | Sketche | Each group performs. The audience gives one *Das war toll, weil ...* after each skit. |
| 0:45–1:05 | Wir singen | *O Tannenbaum* and *Stille Nacht*, verse 1 (on the insert). Read the lyrics aloud once before singing. |
| 1:05–1:35 | Weihnachtskarten | Students write a card using the phrase bank. |
| 1:35–2:00 | Feiern | Snacks, music, free conversation. Prompt with *Was machst du in den Ferien?* |

**Materials:** the insert (one per student), card stock or folded paper, markers, whatever snacks the program provides.

## Feedback on the skits

Respond to content and delivery, not grammar. Good prompts for the audience: *Wer war am lustigsten? Was wollte das Kind?* For the actors: one thing that worked (eye contact, loud enough, didn't read from the page). Save corrections for another day; today the point is that they performed in German.

## Wortschatz

| Deutsch | English |
| :--- | :--- |
| Frohe Weihnachten! / Frohes Fest! | Merry Christmas! / Happy holidays! |

| Das war toll, weil ... | That was great, because ... |
