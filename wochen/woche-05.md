## Grammatik

**Weather uses *es*.** Two patterns:

- *Es ist* + adjective: *Es ist kalt / kühl / windig / sonnig / neblig.*
- *Es* + a weather verb: *Es **regnet**. Es **schneit**.*

**Seasons are all masculine** and take *im* for "in": *im Herbst, im Winter, im Frühling, im Sommer.*

**B1/B2: *wenn* + verb to the end.** Same word order as *weil* from Week 1: *Wenn es kalt **ist**, ...* When the *wenn*-clause comes first, the next clause starts with its verb: *Wenn es kalt ist, **trage** ich einen Pullover.* You get verb, comma, verb.

{: .warning }
**What students will do:** mix the two patterns into *"Es ist regnen."* Answer with the verb: *"Ja, es regnet!"* The other classic: *"Ich bin kalt"* means "I'm a cold person." To say you feel cold, it's ***Mir ist kalt.*** This comes up naturally in a fall lesson, and students remember it because it sounds strange.

The packet's grammar note says *wenn* "recycles" earlier weeks. Weeks 1–4 taught *weil*, not *wenn*, so introduce *wenn* as "works just like *weil*."

## Wortschatz

| Deutsch | English |
| :--- | :--- |
| Es ist kalt / kühl / mild / windig. | It's cold / cool / mild / windy. |
| Es ist neblig / sonnig / regnerisch / wolkig. | It's foggy / sunny / rainy / cloudy. |
| Es regnet. / Es schneit. | It's raining. / It's snowing. |
| Die Blätter fallen. / Die Blätter sind bunt. | The leaves are falling. / The leaves are colorful. |
| der Frühling / der Sommer / der Herbst / der Winter | spring / summer / fall / winter |
| im Herbst | in the fall |
| die Lieblingsjahreszeit | favorite season |
| die Ernte / ernten | the harvest / to harvest |
| das Erntedankfest | harvest festival |
| der Kürbis / der Apfel (die Äpfel) / die Suppe | pumpkin / apple (apples) / soup |
| Wenn es kalt ist, trage ich einen Pullover. *(B1/B2)* | When it's cold, I wear a sweater. |
| Mir ist kalt. | I'm cold. |
