# Woche 4 | Zuhause & Zimmer
October 18, 2026
{: .fs-5 .text-grey-dk-000 }

## Auf einen Blick

| A1 can-do | B1/B2 can-do |
| :--- | :--- |
| Name rooms and furniture and describe where things are | Compare my home with a partner's home |

**Kernaufgabe:** Zimmerbeschreibung. Partner A picks a room picture and keeps it hidden, then describes it in German. Partner B draws the room from the description alone. They compare the drawing with the picture, then switch. A1/A2 place 4–5 items; B1/B2 place at least 7 with at least two different prepositions.

{: .important }
The room pictures are **not in the packet.** Print or sketch 2–3 simple floor plans (a bedroom with a bed, desk, lamp, rug and window is enough) before class.

## Grammatik

**Prepositions of place, as chunks.** A1/A2 learn the phrases whole: *auf dem Tisch, unter dem Bett, im Zimmer.* B1/B2 get the pattern behind them:

When the question is ***Wo?*** (where is it?), the article after the preposition changes:

| | der-words | das-words | die-words |
| :--- | :--- | :--- | :--- |
| Normal | der Tisch | das Bett | die Küche |
| After a place preposition | auf **dem** Tisch | unter **dem** Bett | in **der** Küche |

Two contractions show up constantly: ***im*** = in dem (*im Wohnzimmer*), ***am*** = an dem (*am Fenster*).

The prepositions this week: *in* (in), *auf* (on top of), *unter* (under), *über* (above), *neben* (next to), *an* (at, on a wall), *vor* (in front of), *hinter* (behind), *zwischen* (between).

{: .warning }
**What students will do:** keep the dictionary article (*"auf der Tisch"*) or skip it. In the drawing task, a partner still knows where the table goes, so treat it as a success. If a B2 asks why some sentences use *den* instead (*Ich lege das Buch auf **den** Tisch*): that's for movement toward a place (*Wohin?*), and it's not this week's slice.

## Wortschatz

| Deutsch | English |
| :--- | :--- |
| Ich wohne in einem Haus / einer Wohnung. | I live in a house / an apartment. |
| In meinem Haus gibt es ... Zimmer. | There are ... rooms in my house. |
| das Wohnzimmer / das Schlafzimmer / das Badezimmer / das Esszimmer | living room / bedroom / bathroom / dining room |
| die Küche | kitchen |
| der Garten / die Garage / der Keller | yard, garden / garage / basement |
| Mein Lieblingszimmer ist ... | My favorite room is ... |
| das Bett / der Schreibtisch / der Stuhl | bed / desk / chair |
| der Schrank / das Regal / die Lampe / der Teppich | closet, wardrobe / shelf / lamp / rug |
| das Fenster / die Tür / die Wand | window / door / wall |
| im Wohnzimmer / in der Küche | in the living room / in the kitchen |
| auf dem Tisch / unter dem Bett | on the table / under the bed |
| neben dem Fenster / über dem Schreibtisch | next to the window / above the desk |
