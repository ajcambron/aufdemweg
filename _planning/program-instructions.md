## How every lesson plan should get built here

1. Call the `making-communicative-language-teaching-happen` skill before drafting anything — at minimum for the week's core task design, and again for any specific technique (structured input, oral testing, a reading lesson) as needed. Lesson design follows Lee & VanPatten, not a grammar-syllabus default.
2. Anchor the week to a single concrete task (the "gazebo") — something learners point at and complete, not a grammar point. Pull vocabulary, structures, and functions from that task, not the other way around.
3. Sequence every module input-before-output: learners process comprehensible input and do something with it (structured input, referential then affective questions) before they're asked to produce anything themselves.
4. Build the packet using the module template below, tiered A1–B2 within each module rather than as four separate lesson plans.
5. Output as a two-part deliverable: a student-facing packet (handout, one per student) and a one-page instructor guide (timing, answer keys, skip guidance) that is displayed as a page on the project's Hugo page. Default to a Print Ready PDF for both since they need to be printed.

## Why this structure

The instructor is a resource person and architect, not the sole transmitter of every fact (the "Atlas Complex" the book warns against). Concretely: put the information learners need on cards, texts, or realia and let them get it from each other or from short authentic input, rather than the instructor supplying everything from the front of the room. This also happens to be what makes a packet skippable — a module built as a self-contained info-exchange task can be dropped whole without unraveling the lesson, where a module built as "teacher explains X" cannot.

## The 2.5-hour packet model

Every weekly packet is built from the same modules, tiered by level, so the actual 2-hour class always has room to breathe and the instructor decides what to cut on the fly. Core modules alone run about 85 minutes — comfortably under the 120-minute class. Optional modules add up to 65 more minutes of legitimate content, not filler, so nobody runs out of material and nothing feels like padding when it gets skipped.

| Module | Minutes | Core / Optional | What it does |
|---|---|---|---|
| Einstieg (warm-up) | 10 | Core | Low-stakes activation — picture talk, quick poll, TPR. Whole class together regardless of level. |
| Input & structured input | 20 | Core | Comprehensible input (text/dialogue/short audio) at two reading levels, followed by referential-then-affective questions. Learners respond to input; they don't yet produce the target form. |
| Core info-exchange task | 30 | Core | The week's gazebo task. Partner or small-group information gap, jigsaw, or survey — tiered by role-card complexity, not by a different activity per level. |
| Structured output | 20 | Core | Guided production building on the info-exchange task. A1/A2 get sentence frames and word banks; B1/B2 get open prompts with a required form and a real listener who responds. |
| Können-Sie...? exit ticket | 5 | Core | Two-minute can-do self-check, own-level version. |
| Landeskunde (culture corner) | 15 | Optional | Culture as content — regional custom, image set, or short authentic clip tied to the week's theme. |
| Vocabulary game / energizer | 15 | Optional | Physical or fast-paced review (relay, charades, Kahoot-style). First thing to cut if the class is behind. |
| B1/B2 extension | 20 | Optional | Authentic text, song lyrics, or debate prompt for fast finishers or a stronger sub-group; can run as a station while others finish structured output. |
| Buffer / instructor's choice | 15 | Optional | A second game, extra practice, or review of a prior week — instructor's call. |

Differentiation happens inside each module, not by writing four separate lessons: same theme, same task, tiered input complexity, tiered response scaffolding (sentence frames → free production), and tiered grammar expectations (present tense only at A1, subordinate clauses and Konjunktiv II entering at B1/B2).

## Scope and sequence

26 regular sessions, one class themed around planning for the Christmas Party with a short skit (Nikolaustag falls on an actual class day), one pure celebration day (Weihnachtsfeier), and a closing ceremony (Abschlussfeier). Themes lean into whatever the real calendar date already gives you — Nikolaustag on Dec 6, Valentinstag on Feb 14, and Karnevalssonntag on Feb 7 are the actual dates in 2026–27, not approximations.
