# Lesson Frameworks

Built from Lee & VanPatten, *Making Communicative Language Teaching Happen* (2nd ed.). This folder starts with an underscore, so Jekyll never publishes it.

Every page on the site has three parts: a grammar overview, vocab with definitions, and a worksheet. The book's research pushes on all three, so this doc sets how each one is built. It doesn't change the three parts themselves.

---

## 1. The governing rule: a task first, then everything it needs

Each page ends in a **task** (die Aufgabe): a finished product you can point to and say "done." A chart, a drawing, a short paragraph, a ranked list. "Learn the accusative" is not a task. "Draw your partner's room from their description, then decide whose room is messier" is.

Write the task first. Then ask what students need to *do* it:

| Ask | Becomes |
| :--- | :--- |
| What words does the task need? | **Wortschatz** section (and nothing extra) |
| What grammar does the task need? | **Grammatik** section, usually a *slice* (one case, one gender, two verb persons), not a full chapter |
| What phrases does the task need? (asking, agreeing, comparing) | **Redemittel** box inside Wortschatz |
| What will students hand in? | Last section of the **Arbeitsblatt** |

The book's diagnostic example: a "daily routines" chapter teaches twenty reflexive verbs, and students describing their real routines use almost none of them. Cut what the task doesn't need. It can return on a later page, where some other task needs it.

## 2. Page anatomy

Every page follows this order. Students see the task first, so the vocab and grammar have a reason to exist.

```
# [Thema]
## Die Aufgabe          (2 to 3 sentences: what you'll make and hand in)
## Wortschatz           (grouped by what the task needs, not alphabetically)
## Grammatik            (one form, one minute of reading, one warning)
## Arbeitsblatt         (A–B referential input → C affective input → D structured output → E the task)
## Zusammenfassung      (the paradigm table, at the bottom, as a summary)
```

### Wortschatz: bind the word to the meaning, not to English

The book's term is **binding**: a word sticks when it is tied to its meaning (an image, an object, a situation). A translation only ties it to another word. An English-only list is good enough for flashcard review, but it shouldn't be the only definition.

Each entry has four columns:

| Wort | Bild / Beispiel | Definition (auf Deutsch, einfach) | English |
| :--- | :--- | :--- | :--- |
| der Schreibtisch, -e | 🖼 or *Ich mache meine Hausaufgaben am Schreibtisch.* | ein Tisch für die Arbeit | desk |

- Nouns always carry article and plural. Gender is a property of the word, so it is learned with the word.
- The German definition uses only words students already have. If you can't write one, the example sentence carries the meaning on its own.
- English goes last. It's the safety net, not the definition.
- Group entries by task function ("Möbel," "Wo ist es?," "Meinungen"), not A–Z. (Word banks on worksheets stay alphabetized; that's a different job.)

### Grammatik: short, one thing, with a warning

The research finding that should shape this section: **explanation alone produced no measurable gain** (VanPatten & Oikennon 1996; Benati 2003). What changed students' internal grammar was the *structured input* activities. So the overview is short on purpose, and the worksheet does the teaching.

1. **One form, one function.** "Masculine nouns change *der* → *den* when they are the thing being acted on." Not the full four-case, three-gender table.
2. **One minute of reading.** Three to five sentences, one or two examples.
3. **An Achtung callout (`{: .warning }`) naming the trap.** Name the shortcut students' brains will take, and tell them not to take it (see Section 4).
4. **The full paradigm goes in Zusammenfassung at the bottom.** The book shows students who learned paradigms first reciting them mid-sentence ("ich bin, du bist, er ist... ist!"). A table is useful as a big-picture summary *after* the input work, not as the first thing students see.

### Arbeitsblatt: input before output, always

The worksheet is where acquisition happens, so it follows a fixed sequence. The order matters. Output practice before input processing was the weaker condition in every study the book reviews.

| Section | Type | Student does | Student never |
| :--- | :--- | :--- | :--- |
| **A, B** | Referential structured input (2–3 items types, 6–10 items) | Chooses, matches, marks true/false. There is a right answer, and the form is the only way to get it. | Writes the target form |
| **C** | Affective structured input | Agrees/disagrees, checks what's true *for them*, ranks. No right answer. | Writes the target form |
| **D** | Structured output | Writes or says new information about themselves using the one form. **A partner must respond to the content** (compare, sign, chart it, say "ich auch / ich nicht"). | Recites known information |
| **E** | Die Aufgabe | The page's task. Information exchange with a product. | Works alone |

Two rules apply to every A–D item:

- **The nonsense-word test.** Replace the content words with nonsense. If the item can still be completed, it's a pattern-spotting drill, not meaning-based input. "Circle every *den*" fails. "Who is doing the seeing, the dog or the man?" passes.
- **Remove the shortcut.** If a time word, pronoun or word order gives the answer away, the student never has to process the form. Strip it (Section 4 lists the German shortcuts).

Fill-in-the-blank items belong in D at most, and only when the blank is new information about the student, not a conjugation. When blanks appear, the alphabetized single word bank rule applies.

## 3. The class-hour cycle

A page is not always one class period. Size it by workload: a heavy vocab page can take two days, and two light grammar slices can share one.

Inside every class hour, run the same cycle:

1. **Input first (15–20 min for new vocab).** Teacher talk anchored in pictures, objects and the room itself. Talk slowly, repeat, restate, ask either/or questions ("Ist das ein Stuhl oder ein Tisch?"). Students answer with a word, a gesture, *ja/nein*.
2. **Structured input** (Arbeitsblatt A–C).
3. **Structured output** (Arbeitsblatt D).
4. **End on something you can point to**: Arbeitsblatt E, or a sub-task that builds toward it.

**Teach repair phrases in week one** and post them: *Wie bitte? · Noch einmal, bitte. · Langsamer, bitte. · Was bedeutet ___? · Wie sagt man ___ auf Deutsch?* Students who can signal "I didn't get that" make your input comprehensible for you, and you stop being the only person in the room responsible for understanding (the book calls that the "Atlas Complex").

**Homework** extends the class. Listening with a purpose, structured input practice, a step toward the task. Not conjugation drills.

## 4. Three framework variants, by grammar problem

German grammar points fail in three distinct ways, and each needs a differently built worksheet. Before designing any page, decide which variant you're in.

### Variant 1: The ending carries the meaning, but a word gives it away (Lexical Preference)

**Applies to:** verb person endings (-e, -st, -t), Perfekt, Präteritum, plurals, future with *werden*.

**The trap:** when a word and an ending both carry the same meaning, learners read the word and skip the ending. *Gestern* tells them "past," so *habe ... gespielt* never gets processed. *Du* tells them "you," so *-st* is invisible.

**Build rule:** strip the giveaway word from A–C items. No time adverbs in tense items. No subject pronouns in person-ending items: blank the subject and let the ending answer "Who is this about?" (*\_\_\_ spielst gern Fußball.* → ich / du / Max).

**Sample A item (Perfekt vs. Präsens):** Teacher reads aloud, students mark *jetzt* or *schon passiert*:
> "Lena hat Pizza gegessen." · "Lena isst Pizza." · "Jonas hat Fußball gespielt."

**Sample C item:** "Ich habe heute Morgen gefrühstückt." → *Ich auch / Ich nicht.*

### Variant 2: Word order hides who did what (First Noun Principle)

**Applies to:** Akkusativ and Dativ articles, verb-second with a fronted object, *dass/weil* verb-final clauses, passive.

**The trap:** learners assume the first noun is the one doing the action. In "Den Hund beißt der Mann," English-speaking students see a dog biting a man. German puts objects first constantly, so this trap shows up all year.

**Build rule:** write A items where the object comes first and only the article tells you who acts. **Use masculine nouns only.** Feminine, neuter and plural articles look the same in nominative and accusative (*die/die, das/das*), so those sentences are ambiguous and can't test anything. Pair each sentence with a picture choice: two drawings, one for each reading.

**Sample A item:** "Wer sieht wen?" Students pick picture 1 (man sees dog) or picture 2 (dog sees man):
> "Den Mann sieht der Hund." · "Der Hund sieht den Mann." · "Den Lehrer findet der Schüler nett."

**Sample C item:** "Den Montag finde ich furchtbar." → *Stimmt / Stimmt nicht.*

### Variant 3: The form barely matters to meaning (low communicative value)

**Applies to:** adjective endings, gender agreement on articles, *zu*-infinitives, many prepositions' case.

**The trap:** "ein großer Hund" and "ein große Hund" mean the same thing to a listener, so learners stop processing the ending until comprehension gets easy. Adjective endings are the classic case, and drilling them early mostly produces frustration.

**Build rule:** keep these mostly as input for a long stretch. Expose them in reading and listening, highlight them in context, and don't build D or E sections that grade the ending. When you do teach one, choose items where the ending *does* carry meaning, such as an ending that tells you which of two nouns the adjective goes with.

**Assessment rule:** don't heavily weight these forms on early quizzes. The acquisition order means students will produce them late regardless of how they're taught.

## 5. Worked example: "Mein Zimmer"

**Die Aufgabe:** Partner A describes their room (8 items, where they are). Partner B draws it without looking. Swap. Together, decide whose room is *ordentlicher* and write one sentence why. **Hand in:** both drawings and the sentence.

**What the task needs:**

| Need | Slice |
| :--- | :--- |
| Wortschatz | ~14 furniture/objects nouns with articles; *links, rechts, neben, an der Wand, auf dem Boden*; *ordentlich, unordentlich, groß, klein* |
| Grammatik | Akkusativ after *haben* and *es gibt*, **masculine only**: *einen, keinen*. (Feminine and neuter look the same; tell students that, and it's a relief, not a rule.) |
| Redemittel | *Hast du einen ___? · Wo ist ___? · Noch einmal, bitte. · Mein Zimmer ist ordentlicher, weil ___.* |
| Variant | 2 (First Noun) for A, B. The task itself has low pressure on case, so case errors in E aren't graded. |

**Arbeitsblatt:**

- **A (referential, listening):** Teacher describes a drawn room. Students mark items *ja, im Zimmer / nein* on a picture grid. "Es gibt keinen Teppich. Es gibt einen Stuhl..."
- **B (referential, reading, Variant 2):** "Wer hat wen?" 6 sentences with fronted masculine objects, two picture choices each: "Den Hund hat der Junge. Den Jungen hat der Hund (im Maul)." Keep it a bit silly; silly sentences get processed.
- **C (affective):** Check every sentence true for you: "Ich habe einen Fernseher im Zimmer. · Ich brauche keinen Schreibtisch. · Einen Teppich finde ich wichtig."
- **D (structured output):** Write 5 things you have and 3 you don't (*Ich habe einen / keinen ___*). Partner reads them and marks each *ich auch / ich nicht*. Then count: who has more of the same things?
- **E:** Die Aufgabe.

**Zusammenfassung:** the four-gender nominative/accusative table, with the masculine column highlighted as "the only one that changes."

**Two days:** Day 1 is vocab input (teacher-described room, picture grid) + A. Day 2 is Grammatik + B, C, D, E.

## 6. Assessment: test what you taught, the way you taught it

The book's warning: a fill-in-the-blank conjugation test after input-based teaching tells students the input work didn't count, and next unit they stop doing it. Build quizzes from the worksheet's own formats.

| Quiz section | Format | Example |
| :--- | :--- | :--- |
| 1. Interpretation | Same as Arbeitsblatt A/B, new sentences | "Wer sieht wen?" picture choice, 4 items |
| 2. Production | Same as D, new prompt | "Write 3 things you have and 2 you don't" |
| 3. Class content | Questions about what classmates said in E | "Whose room was messier? Why?" |

- **Item counts follow importance.** Three items is fine; don't pad to ten.
- **Score componentially.** For writing or speaking: content (did they communicate the information?), vocabulary, the page's one grammar form. Share the weights with students before the task.
- **Listening items get nonlinguistic answers** (draw, choose a picture, check a box). If students must write German sentences to show they understood, you're testing writing.

## 7. Quick checklist before a page is done

- [ ] Die Aufgabe has a hand-in product and appears before Wortschatz.
- [ ] Every vocab entry is used by the task; every entry has article + plural, a picture or example, a German definition, English last.
- [ ] Grammatik covers one form, reads in about a minute, and has an Achtung (`{: .warning }`) callout naming the processing trap.
- [ ] The variant (1, 2 or 3) is decided, and A–B items have the shortcut removed.
- [ ] A–C never ask students to write the target form.
- [ ] D requires a partner to respond to the content.
- [ ] Every A–D item passes the nonsense-word test.
- [ ] The full paradigm appears only in Zusammenfassung.
